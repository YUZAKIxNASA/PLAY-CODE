# HTML Basics

This lesson covers the core structure and essential tags used in HTML.

## 1. HTML Declaration
```html
<!DOCTYPE html>
<html>
  <body>
    <h1>Welcome</h1>
  </body>
</html>
```

## 2. Sample Code
```html
<p>This is a paragraph.</p>
<h2>This is a heading.</h2>
```

## 3. Paragraph and Heading Tags
```html
<p>This is a paragraph.</p>
<h1>Heading 1</h1>
<h6>Heading 6</h6>
```

## 4. BR and HR Tags
```html
<p>Line one<br>Line two</p>
<hr>
```

## 5. Text Formatting
```html
<strong>Strong text</strong>
<em>Emphasized text</em>
<small>Small text</small>
<mark>Marked text</mark>
<del>Deleted text</del>
<ins>Inserted text</ins>
<sub>Subscript</sub>
<sup>Superscript</sup>
```

## 6. Semantic and Generic Tags
```html
<abbr title="HyperText Markup Language">HTML</abbr>
<cite>Example citation</cite>
<address>Contact info</address>
<q>Quoted text</q>
<blockquote>Long quotation</blockquote>
<pre>Line 1
Line 2</pre>
<span>Inline content</span>
<div>Block content</div>
```
