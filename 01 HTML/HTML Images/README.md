# HTML Images

Images are embedded with the img tag and can be styled or controlled with attributes.

```html
<img src="image.jpg" alt="Example image" width="300" height="200" loading="lazy" />
```

## Related Tags
```html
<figure>
  <img src="photo.jpg" alt="Photo" />
  <figcaption>Figure caption</figcaption>
</figure>

<img src="map.png" alt="Map" usemap="#map" />
<map name="map">
  <area shape="rect" coords="0,0,100,100" href="#" />
</map>
```
