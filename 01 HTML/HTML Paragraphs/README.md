# HTML Paragraphs

Paragraphs and inline formatting are the building blocks of text content.

```html
<p>This is a paragraph.</p>
<p>Use &nbsp; for a non-breaking space.</p>
<p contenteditable="true">You can edit this text.</p>
```

## Common Character Entities
```html
<p>5 &lt; 10</p>
<p>Tom &amp; Jerry</p>
<p>Copyright &copy;</p>
```
