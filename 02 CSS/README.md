# CSS

This section includes beginner-friendly CSS lessons organized by topic.

## Topics Covered
- Selectors and combinators
- Colors, text, fonts, and spacing
- Box model, display, flexbox, and grid
- Positioning, transitions, transforms, and animations
- Media queries, gradients, shadows, and advanced styling

## Quick Example
```css
body {
  font-family: Arial, sans-serif;
  background-color: #f4f4f4;
  color: #222;
}

.box {
  padding: 20px;
  margin: 10px;
  border: 1px solid #ccc;
}
```
